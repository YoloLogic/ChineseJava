# 在 VS Code 里用 ChineseJava（中文关键字）

## 一、最快路径：用本目录自带的构建任务

1. 打开本目录：
   ```powershell
   & "C:\Users\hp\AppData\Local\Programs\Microsoft VS Code\Code.exe" "E:\ChineseJava\examples\vsCode演示"
   ```
2. 打开 `甲类.java`
3. 按 **Ctrl+Shift+B**（运行默认生成任务）→ 编译
4. **Ctrl+Shift+P** → `Tasks: Run Task` → 选 `ChineseJava: 编译并运行`

任务配置在 `.vscode/tasks.json`，里面用的是**本仓库自己构建的 javac**：

```
E:\ChineseJava\jdk\build\cnjava\images\jdk\bin\javac.exe -encoding UTF-8 ...
```

> `-encoding UTF-8` 建议**显式写**。javac 的默认源码编码跟随系统代码页：
> 本机系统开了「Beta: 使用 Unicode UTF-8」（ACP=65001），所以不写也能读 UTF-8；
> 但如果拿到没开 UTF-8 的中文 Windows（ACP=936/GBK），UTF-8 源码里的中文会被读坏并报
> `编码 UTF-8 的不可映射字符`。任务里写死它，就不依赖目标机器的系统设置。

## 二、⚠️ 任务必须是 `"type": "process"`，不能是 `"shell"`

这是踩过的真坑，写在这里免得再犯：

```
错误: 找不到或无法加载主类 .encoding=UTF-8
原因: java.lang.ClassNotFoundException: /encoding=UTF-8
```

原因：`"type": "shell"` 会把整条命令**再交给 PowerShell 解析一遍**，而 PowerShell 会把
`-Dstdout.encoding=UTF-8` 拆坏，java 最终收到的参数变成 `.encoding=UTF-8`（被当成主类名）。

修法：任务用 `"type": "process"`，由 VS Code 直接按 `args` 数组传给进程，绕开 shell：

```jsonc
{
  "label": "ChineseJava: 运行当前文件",
  "type": "process",                       // ← 关键
  "command": "...\\bin\\java.exe",
  "args": ["-Dstdout.encoding=UTF-8", "-Dfile.encoding=UTF-8",
           "-cp", "${workspaceFolder}\\out", "${fileBasenameNoExtension}"]
}
```

同样的道理：任何带 `-Dxxx=yyy` 的参数，走 shell 都有这个风险。

## 三、为什么要用任务，而不是 Java 扩展

VS Code **本身不带 Java 支持**。装了微软的 "Extension Pack for Java" 或红帽的
"Language Support for Java" 之后，语言服务器是 **Eclipse JDT**，它有自己的编译器与解析器——
**不认识 `公开`、`类型`、`整数`、`如果` 这些中文关键字**，会把它们全标成红色错误。

所以：

| 诉求 | 能不能满足 | 做法 |
|---|---|---|
| 编译 / 运行中文源码 | ✅ 能 | 上面的构建任务（调用我们的 javac） |
| 中文诊断（报错是中文） | ✅ 能 | 任务面板里显示的就是我们 javac 的中文输出，且带 `file:line` 可点击跳转 |
| 语法高亮、跳转、补全 | ⚠️ 不完整 | 装 Java 扩展后英文部分正常，中文关键字会被标错 |
| 断点调试 | ⚠️ 未验证 | 需要用我们的 java + jdwp 手工配 launch，且 JDT 可能先拦 |

## 三、想只保留高亮、不想要 JDT 的红波浪

在设置里关掉 Java 扩展对这些文件的校验（`java.validate.enabled` / `files.associations`），
或者干脆**不装 Java 扩展**——本演示只靠任务就够跑通。

## 四、换机器要改的唯一一行

`.vscode/tasks.json` 里三处 `E:\\ChineseJava\\jdk\\build\\cnjava\\images\\jdk\bin\*.exe`，
以及 `.vscode/settings.json` 里的 `java.jdt.ls.java.home` / `JAVA_HOME`。
