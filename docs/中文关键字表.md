## 八、定则与裁定记录

**R1（跨语言词位）**：同一门语言内禁止撞词；跨语言可复用同一概念词。

- `open` / `opens` → `开放` / `开放包`：两个不同的 Java 关键字，会同时出现在同一个 `module-info.java` 里 ⇒ 必须拆。
- `exports` → `导出`：跨语言复用 C++ 的 `export`（同一概念，且分属两种语言、永不共存）。
- `uses` → `使用`：跨语言重词（C++ `using`、Python `with` 亦为「使用」），已登记为记账项。

**R2（字数）**：每个中文拼写必须 2–6 个**汉字**（按汉字数算，不按 `len()`），唯一、可切分。

**R3（强度镜像）**：强度照抄 JLS 分类 —— 保留关键字硬、上下文关键字/受限标识符软、`_` 不译；字面量按 Java 现状亦为硬。

**R4（同词根两词要加限定）**：`final`→`最终` / `finally`→`最终必须`；`throw`→`抛出` / `throws`→`声明抛出`。

**R5（一个中文词只服务一个英文概念）**：C++ 的 `requires` 已占 `约束`，Java 的模块依赖改用 `依赖`。

**生成时间口径**：本表由生成器生成，内容只依赖 `tools\关键字表.tsv` 与上游树，不含时间戳（保证 `-Check` 可复现）。
