# 示例说明

两个文件是**同一个程序**：

| 文件 | 写法 |
|---|---|
| [中文示例/甲类.java](中文示例/甲类.java) | 全中文关键字（`公开 类型 密封 许可 非密封 记录 自动 选择 情形 符合 最终 返回`） |
| [英文对照/甲类.java](英文对照/甲类.java) | 全英文关键字（`public class sealed permits non-sealed record var switch case when final return`） |

**两者编译出的字节码完全一致**（类名与标识符在两版里相同，只有关键字拼写不同）——这是本项目的核心性质：
中文是**并列多出来的拼写**，不是替换。

## 跑一下

```powershell
$J = 'E:\ChineseJava\jdk\build\cnjava\images\jdk'      # 换成你的镜像路径

# 中文写法
& "$J\bin\javac.exe" -d out\中文 examples\中文示例\甲类.java
& "$J\bin\java.exe"  -cp out\中文 甲类

# 英文写法
& "$J\bin\javac.exe" -d out\英文 examples\英文对照\甲类.java
& "$J\bin\java.exe"  -cp out\英文 甲类

# 对拍：两个 .class 的 SHA256 应当相同
(Get-FileHash out\中文\甲类.class -Algorithm SHA256).Hash
(Get-FileHash out\英文\甲类.class -Algorithm SHA256).Hash
```

## 这个例子里用到了什么

- **硬关键字**：`公开 public`、`类型 class/interface`、`密封 sealed`、`许可 permits`、`非密封 non-sealed`、`记录 record`、
  `最终 final`、`返回 return`、`选择 switch`、`情形 case`、`默认 default`、`新建 new`、`静态 static`、`空型 void`、`整数 int`、`双精度 double`
- **软关键字**：`自动 var`（局部变量类型推断）、`符合 when`（模式守卫）—— 位置敏感，**不占标识符空间**
- **中英混写**：中文示例里故意保留了 `for (形状 形 : 图形)` 这个纯英文 `for`
- 标准库名（`System.out.println`）**仍是英文**：L3 中文标准库名字层还没做（见 [README](../README.md) 的层级表）
